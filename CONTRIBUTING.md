# Contribuindo com o VideoLocal

## Alterações

- Mantenha o aplicativo simples e compatível com Windows.
- Não adicione executáveis, o ambiente `.venv`, downloads ou configurações locais ao Git.
- Não inclua cookies de navegador, credenciais, tokens ou dados pessoais em commits.
- Use apenas dependências necessárias e declare-as em `requirements.txt`.
- Atualize este README quando mudar instalação, formatos ou requisitos.

## Revisão antes de enviar

- Confira `git status` e a lista de arquivos preparados.
- Confirme que `.venv`, `bin`, `doc`, `presets` e `ffmpeg_path.txt` não estão no commit.
- Execute verificações adequadas às alterações e descreva limitações no pull request.
